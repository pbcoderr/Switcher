# История изменений

## 1.1.0.0 — 2026-10-08

### Тихий и компактный интерфейс

- Убраны всплывающие уведомления при работе и отдельное сообщение об успешной установке.
- Инструкции перенесены в окно «Помощь», ошибки показываются внутри окон и в статусе трея.
- Добавлена остановка маршрутизации из трея с сохранением подключения Tailscale.
- Уменьшена высота основных окон.

### Автозапуск исключений

- Сохранённые исключения автоматически запускаются вместе с Tailscale, включая запуск Switcher при активном подключении.
- Переключение на zapret автоматически завершает маршрутизацию.
- Ручная остановка приостанавливает автозапуск до следующего подключения; ошибки запуска повторяются с интервалом в минуту.
- Окна и таблицы стали компактнее.

### Обновлён интерфейс

- Графитовая тема с нежно-голубыми акцентами в настройках, маршрутизации, импорте и меню трея.
- Новая иконка приложения: заострённая буква S. Обновлены значки T, Z, R и состояний.

### Переработана маршрутизация

- Используется установленный Tailscale, существующий вход и выбранный в нём exit node.
- Tailscale остаётся подключённым. Второй клиент и устройство switcher-routing больше не создаются.
- Убраны отдельный вход и выбор сервера в Switcher.
- Исключения напрямую; остальной интернет через интерфейс обычного Tailscale.
- Временные правила Windows привязаны к сеансу процесса и удаляются даже после аварийного завершения.
- Движок завершается вместе со Switcher; его адаптер и маршруты также удаляются.
- Постоянные маршруты, правила брандмауэра и DNS существующих интерфейсов не изменяются.
- При изменении подключения правила останавливаются; их можно включить заново.
- Совместимый режим IPv4: недоступный IPv6 отклоняется до установления соединения, чтобы приложения могли выбрать IPv4. IPv6-only интернет-ресурсы не поддерживаются.

### Сохранены функции

- Переключение Tailscale ↔ zapret, настройки папок, стратегии и горячих клавиш.
- Импорт TXT, LIST, JSON и CSV с предварительным просмотром и проверкой ошибок.
- Встроенный sing-box 1.14.2, проверка SHA-256 и комплект лицензий/исходников.
- Первый запуск без личных настроек автора.

### Проверено

- Разные внешние IP для прямого исключения и трафика через exit node.
- Яндекс, страница Музыки и Google открываются при работающем обычном Tailscale.
- Устройство Tailscale и exit node остаются прежними.
- Принудительное завершение тестового процесса удаляет все временные WFP-правила и адаптер.

Перед обновлением останови старую маршрутизацию. Старое устройство switcher-routing автоматически не удаляется; оно больше не используется.
