# История изменений

## 1.1.0.0 — 2026-10-08

- Исправлены сбросы соединений в сетях без рабочего IPv6: DNS движка теперь использует IPv4.
- Ранее виртуальный IPv6-интерфейс заставлял приложения выбирать недоступные IPv6-адреса. Проверка только IPv4-адресов этот сбой не выявляла.
- После обновления требуется перезапустить браузер и Музыку для очистки их старых DNS-кэшей.
- Подключения к адресам, доступным только по IPv6, в текущем режиме не поддерживаются.
- Проверено без принудительного IPv4: yandex.ru и сайт Музыки открываются, API отвечает; разделение прямого трафика и exit node сохраняется. Воспроизведение в пользовательском аккаунте проверяется отдельно.



### Добавлено
- Импорт исключений из TXT, LIST, JSON и CSV.
- Предварительный просмотр, проверка ошибок и пропуск точных дубликатов.
- Поддержка UTF-8, UTF-16 с BOM и Windows-1251.
- Поиск доступных exit node через установленный Tailscale.
- Сохранение последнего журнала в routing-last.log с удалением ссылок входа и ключей.
- Примеры файлов импорта в Examples.

### Изменено
- Единая схема: список — напрямую, остальное — через Tailscale. Выбор направления убран.
- Обновлены README и инструкция обновления со старых правил.

### Исправлено
- Обычный туннель Tailscale теперь отключается также на время отдельного входа встроенного движка. Ранее он мог блокировать подключение к серверу авторизации.
- После закрытия сеанса входа прежние подключения восстанавливаются.
- Короткие и полные DNS-имена exit node сопоставляются с его Tailscale IP.
- Сообщение при отсутствии отдельного входа объясняет, что нужно сделать.

### Проверено
- Сборка Debug и Release, автоматические проверки импорта, конфигурации и восстановления.
- Реальный трафик: исключение напрямую, остальное через exit node; прежние подключения восстановлены.

### Встроенный движок

- sing-box 1.14.2 встроен в EXE, извлекается автоматически с проверкой SHA-256.
- В комплект добавлены лицензия, исходники и сведения о сборке движка.

## Обновление

Останови маршрутизацию, закрой Switcher, распакуй новую сборку и запусти Install.cmd. Настройки и вход сохраняются. Перед публикацией используй чистый архив релиза: не добавляй settings.json, routing*.json, routing-state или журналы.
