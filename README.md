**Переключатель Tailscale ↔ zapret и маршрутизация сайтов и программ для Windows.**

**Версия: 1.1.0.0 · Автор: pb_coder**

Switcher работает в системном трее и переключает Tailscale и zapret одним сочетанием клавиш. Папки программ, стратегию zapret и горячие клавиши можно выбрать в настройках.

Для раздельного доступа к сайтам и приложениям есть режим маршрутизации: **исключения идут напрямую, остальной интернет — через Tailscale**. Движок sing-box встроен в программу.

## Возможности

- Тихий запуск и переключение: без всплывающих уведомлений. Ошибки видны в статусе, подробности открываются вручную.
- Кнопка «Помощь» в трее и основных окнах: инструкции, примеры правил и объяснение режимов.
- «Выключить маршрутизацию» прямо в трее — без отключения Tailscale.

- Автоматический запуск сохранённых исключений при подключении Tailscale и при запуске Switcher с уже подключённым Tailscale.
- Компактные окна настроек, маршрутизации и импорта.

- Графитовый интерфейс с нежно-голубыми акцентами, новая иконка S и обновлённые значки трея.

- Переключение между подключением Tailscale и службой zapret.
- Иконки **T**, **Z** и **R** для подключения Tailscale, службы zapret и маршрутизации.
- Настраиваемые горячие клавиши переключения и выхода.
- Выбор папок Tailscale и zapret через окно настроек.
- Выбор стратегии zapret из `.bat`-файлов: ALT11, ALT12, FAKE TLS AUTO и другие.
- Проверка результата и попытка восстановления предыдущего режима при ошибке.
- Сохранение настроек между запусками.
- Автозапуск при входе в Windows через Планировщик заданий.
- Запуск установленной копии с правами администратора без повторного запроса UAC.
- Маршрутизация: сайты, IP / подсети и программы из списка — напрямую, остальное — через Tailscale.
- Импорт исключений из TXT, LIST, JSON и CSV с предварительным просмотром и проверкой ошибок.
- Использование exit node обычного Tailscale, быстрые исключения для .ru, .рф, .su и журнал диагностики.

## Требования

- Windows 10/11 **x64** с .NET Framework **4.7.2** или новее для готовой сборки со встроенным движком.
- Учётная запись администратора для установки и управления службами.
- Установленный Tailscale с выполненным входом в аккаунт.
- Распакованный zapret с установленной службой `zapret`.

Чтение стратегий проверено на **zapret-discord-youtube 1.10.2**. Произвольные `.bat`-скрипты и другие версии могут использовать неподдерживаемый формат.

Tailscale и zapret устанавливаются отдельно и не входят в состав Switcher.

## Установка

1. Подготовь Tailscale и zapret. Если служба zapret ещё не установлена, один раз запусти `service.bat`, выбери пункт **1** и нужную стратегию.
2. Собери Switcher по инструкции ниже либо используй готовую папку сборки.
3. Запусти `Install.cmd` **из папки с `Switcher.exe`**. При сборке проекта это `bin\Release\Install.cmd`.
4. Подтверди запрос прав администратора Windows.
5. Найди иконку Switcher рядом с часами. Она может быть скрыта под стрелкой системного трея.

### Первый запуск
<img width="696" height="489" alt="01-first-launch" src="https://github.com/user-attachments/assets/f9de9119-0d60-4701-a06f-365debc8afb0" />


Если сохранённых настроек нет, автоматически откроется окно **«Первый запуск»**. Папки и стратегия изначально пустые: выбери свою папку Tailscale, папку zapret и нужную стратегию, затем нажми **«Сохранить»**. Горячие клавиши `Ctrl+Alt+F8/F9` предложены как стандартные и доступны для изменения.

До успешного сохранения переключение отключено. Кнопка **«Позже»** оставляет приложение в трее без изменения подключений; вернуться к настройке можно через меню иконки или двойным щелчком. При следующем запуске окно снова появится, если настройка не завершена.

После сохранения приложение запускается в трее. Если файл настроек повреждён или сохранённые папки и файлы больше недоступны, окно настройки откроется повторно. В исходниках нет заранее выбранной папки или стратегии пользователя.

Установщик создаёт ярлык **Tailscale - zapret** на рабочем столе и задачу для запуска при входе в Windows. В дальнейшем используй этот ярлык: повторный запрос UAC для обычного запуска не нужен. При установке или обновлении подтверждение администратора требуется; UAC в системе не отключается.

Приложение устанавливается в `%ProgramFiles%\TailscaleZapretSwitcher`. Тип запуска службы zapret меняется на **Вручную**, чтобы она не запускалась сама рядом с Tailscale после перезагрузки. Исходный тип запуска сохраняется для удаления переключателя.

## Настройки

Открой **«Настройки…»** через меню иконки.
<img width="696" height="489" alt="02-settings" src="https://github.com/user-attachments/assets/d365a14c-ad7a-4a6b-ae71-9621c04dda90" />

| Поле | Что выбрать |
|---|---|
| Папка Tailscale | Папку, содержащую `tailscale.exe` |
| Папка zapret | Корневую папку с `bin\winws.exe` и `.bat`-файлами стратегий |
| Стратегия zapret | Нужную стратегию из списка; `service.bat` исключён |
| Переключить T ↔ Z | Сочетание для смены режима |
| Закрыть переключатель | Отдельное сочетание для выхода |

Чтобы назначить клавиши, нажми на поле и введи сочетание с **Ctrl** или **Alt**. Можно добавить **Shift**. Поддерживаются буквы, цифры и F-клавиши, кроме зарезервированной F12. Для восстановления стандартных сочетаний нажми **«Клавиши по умолчанию»**.

Кнопка **«Обновить»** перечитывает список стратегий из выбранной папки. **«Сохранить»** проверяет пути, необходимые файлы и доступность горячих клавиш. Совпадающие или занятые сочетания не сохраняются. **«Отмена»** оставляет прежние настройки.

На время открытого окна настроек горячие клавиши Switcher отключены, чтобы можно было вводить их в поля.

### Смена стратегии

При смене стратегии или папки zapret Switcher обновляет конфигурацию существующей службы:

- Если zapret работает, выполняется короткий перезапуск.
- Если выключен, новая стратегия применяется без его включения.
- При ошибке выполняется попытка вернуть прежнюю конфигурацию и состояние службы.

Switcher читает команду `winws.exe` из выбранного `.bat`, подставляет пути и текущие настройки игрового фильтра. Сам `.bat` и меню `service.bat` не запускаются. Для обычного переключения не требуется повторно выбирать пункты **1** и **11**.

## Маршрутизация сайтов и программ
<img width="880" height="510" alt="03-routing" src="https://github.com/user-attachments/assets/9f3f2ca9-1446-4759-8230-a0672309fe20" />

**Включённые записи в списке идут напрямую. Всё остальное — через выбранный exit node Tailscale.** Локальная сеть также доступна напрямую. Выбирать направление для каждой записи не нужно.

Открой меню иконки → **«Маршрутизация…»**. Официальный [sing-box 1.14.2](https://github.com/SagerNet/sing-box/releases/tag/v1.14.2) для Windows x64 встроен в EXE. Он автоматически извлекается с проверкой контрольных сумм, отдельная загрузка не нужна.

1. Подключи **обычный Tailscale** и выбери в нём нужный exit node. Используется уже существующее устройство и твой текущий вход.
2. Открой в Switcher **«Маршрутизация…»**.
3. Добавь исключения вручную или импортируй список, нажми **«Сохранить»** и закрой окно. Исключения запустятся автоматически; кнопка **«Включить»** позволяет запустить их сразу в этом окне.

Автозапуск использует сохранённый список с хотя бы одним включённым исключением. В Tailscale должен быть выбран доступный exit node. Внешнее подключение обнаруживается в течение 5 секунд, затем проверяется связь и запускаются правила. Пока открыто окно редактирования, автоматический запуск отложен до его закрытия. При ошибке повторная попытка выполняется через минуту; Tailscale остаётся подключённым. При переключении на zapret исключения сначала удаляются.

Повторный вход и устройство switcher-routing больше не нужны. sing-box работает только как локальный маршрутизатор; второй клиент Tailscale не запускается. Обычный Tailscale остаётся подключённым.

Исключения существуют **только во время работы маршрутизации в Switcher**. Программа создаёт временный адаптер и правила Windows Filtering Platform. При остановке, выходе или аварийном завершении процесса правила автоматически удаляются; дочерний движок завершается вместе со Switcher, его адаптер и маршруты удаляются. Постоянные маршруты, правила брандмауэра и DNS существующих адаптеров не меняются.

Разрешение прямого выхода ограничено комплектным движком и выбранным интернет-интерфейсом. Отдельное временное разрешение даёт приложениям доступ к адаптеру Switcher. Передача данных дальше определяется твоими исключениями.

**«Остановить»** отключает исключения до следующего подключения Tailscale, явного выбора Tailscale в меню или перезапуска Switcher. Обычный Tailscale продолжает работать с тем же exit node. Закрытие окна правил оставляет маршрутизацию работающей в трее; для её завершения нажми кнопку остановки или выйди из Switcher.

| Тип исключения | Пример | Действие |
|---|---|---|
| Сайт + поддомены | example.ru | Домен и его поддомены напрямую |
| IP / подсеть | 203.0.113.0/24 | Указанные адреса напрямую |
| Программа (.exe) | ExampleApp.exe | Соединения процесса с этим именем напрямую |

Кнопка **«.ru / .рф / .su напрямую»** добавляет исключения для этих доменных зон. Это не полный список российских сервисов: дополнительные домены и CDN нужно добавлять отдельно.

### Импорт списков

<img width="800" height="480" alt="04-import" src="https://github.com/user-attachments/assets/047da685-b072-4527-ab86-0d9eda41ebd9" />


Нажми **«Импорт исключений…»**, выбери файл и проверь предварительный просмотр. Импорт добавляет записи к текущим; существующие записи сохраняются. Точные дубликаты пропускаются. Ошибки и конфликтующие записи блокируют весь импорт, чтобы не применять неполный список. Отмена ничего не меняет. После импорта сохрани список и включи маршрутизацию.

Поддерживаются UTF-8, UTF-16 с BOM и Windows-1251. Максимум файла — 1 МБ, максимум итогового списка — 2000 правил.

**TXT / LIST:** один домен, IP, подсеть или HTTP(S)-адрес на строку. У адреса сайта используется только имя хоста. Пустые строки и комментарии с `#`, `//` или `;` пропускаются.

```text
# Напрямую, включая поддомены
example.ru
пример.рф
https://example.org/page
203.0.113.0/24
```

**JSON:** массив строк или объектов; также поддерживаются объекты с массивом `domains` либо `rules`.

```json
{
  "rules": [
    { "kind": "domain", "value": "example.ru" },
    { "kind": "ip", "value": "203.0.113.0/24" },
    { "kind": "process", "value": "ExampleApp.exe", "enabled": true }
  ]
}
```

**CSV:** разделитель — запятая или точка с запятой; для нескольких колонок нужна строка заголовков. Допустимые колонки: `value`, `kind`, `enabled`, `target`. Поле `value` обязательно; `enabled` принимает `true` или `false`.

```csv
value,kind,enabled
example.ru,domain,true
203.0.113.0/24,ip,true
ExampleApp.exe,process,true
```

Направление в файле обычно не нужно. Если поле `target` задано, поддерживается только `direct`: записи с `tailscale` отклоняются. Для программ явно указывай `kind: process` в JSON/CSV; строка `example.exe` в TXT считается доменом. Готовые образцы находятся в [Examples](Examples).

### Проверка и восстановление

Перед включением проверяются конфигурация и TCP-доступ через exit node к `1.1.1.1:443`. Иконка **R** означает работающий движок; она не гарантирует доступность каждого сайта. Изменения применяются к новым соединениям: перезапусти нужную программу или вкладку.

При смене интернет-интерфейса, аккаунта или exit node Switcher останавливает правила при следующей проверке подключения. После изменения подключения включи правила заново. Перед включением нужна одна активная сеть с IPv4-шлюзом; если одновременно активны Ethernet и Wi-Fi, оставь одно подключение.

Маршрутизация рассчитана на **IPv4**. На временном адаптере IPv6-соединения к интернету отклоняются до установления соединения, чтобы приложения могли выбрать IPv4. IPv6-only интернет-ресурсы не поддерживаются. Существующие интерфейсы и их настройки IPv6 не изменяются.

DNS Tailscale остаётся включённым; для перехваченных DNS-запросов движок использует 1.1.1.1, а для имён .ts.net — MagicDNS установленного Tailscale. Собственный защищённый DNS браузера, скрытое имя сервера и общие IP могут мешать доменным исключениям. В таких случаях используй правило по имени программы или IP.

Файлы routing.json и routing-last.log рядом с EXE содержат настройки и последнюю диагностику; они не входят в публичный архив. Настройки сохраняются между запусками, но сами исключения Windows заново создаются только при включении маршрутизации.

### Переход со старой схемы

Останови старую маршрутизацию перед обновлением. Если старая версия аварийно завершилась и оставила routing-recovery.json, сначала нажми «Остановить / восстановить». Новая схема такой журнал не создаёт.

Ранее созданное устройство switcher-routing больше не используется. При желании удали именно это старое устройство в панели Tailscale. Switcher не удаляет устройства твоей сети автоматически и не использует старую папку routing-state.

## Как работает переключение

**В режим zapret:** отключить соединение Tailscale → запустить службу zapret → проверить состояние.

**В режим Tailscale:** остановить службу zapret → дождаться завершения `winws.exe` → подключить Tailscale → проверить состояние.

Повторные команды во время операции игнорируются. Если новый режим не запускается, Switcher пытается восстановить прежний и сообщает об ошибке.

Для Tailscale используются `tailscale up` без флагов и `tailscale down`; сохранённые настройки подключения не сбрасываются.

## Сборка из исходников

1. Установи Visual Studio с компонентом **«Разработка классических приложений .NET»** и пакетом разработки **.NET Framework 4.7.2**.
2. Открой `Switcher.csproj` или `Switcher.slnx`, если версия Visual Studio поддерживает этот формат решения.
3. Один раз запусти `Prepare-Engine.ps1`: он загрузит официальный архив sing-box 1.14.2 и проверит SHA-256. Для работы без сети передай уже скачанный архив через `-ArchivePath`. В готовой пользовательской сборке этот шаг уже выполнен.
4. Выбери конфигурацию **Release** и собери проект.
5. Готовые файлы появятся в `bin\Release`. Для распространения упакуй EXE, установщик, документацию и папку `Engine` с лицензиями и исходниками компонента.

Из командной строки разработчика Visual Studio:

```powershell
.\Prepare-Engine.ps1
msbuild Switcher.csproj /p:Configuration=Release
```

Дополнительные NuGet-пакеты не требуются. Для работы с сетью при отладке через **F5** запусти Visual Studio с правами администратора. При обычном запуске EXE без повышения прав приложение покажет инструкцию установки.

Проверки маршрутизации после Release-сборки:

```powershell
.\Tests\Run-RoutingTests.ps1
```

Проверки охватывают импорт списков, поиск серверов, правила, встроенный движок и восстановление после ошибок. Конфигурация проверяется настоящим sing-box без запуска туннеля; сценарии переключения — с имитацией служб. Действующие подключения не меняются.

## Обновление и настройки

Изменения версий перечислены в [CHANGELOG.md](CHANGELOG.md). Перед обновлением останови маршрутизацию, дождись восстановления подключений и закрой старый переключатель. Собери новую версию и снова запусти `Install.cmd` из папки сборки.

Настройки установленной версии находятся в:

```text
%ProgramFiles%\TailscaleZapretSwitcher\settings.json
```

Установщик сохраняет их, правила и состояние входа при обновлении. Список маршрутизации содержит только прямые исключения: при открытии старого списка записи «через Tailscale» не добавляются в исключения, а программа показывает уведомление. Проверь список и сохрани его, чтобы применить новую схему. При новой установке `settings.json` из папки сборки **не копируется**: пользователь проходит первоначальную настройку. Прямо запущенные Debug/Release-сборки используют отдельные настройки рядом со своим EXE.

Папки сборки, файлы Visual Studio и локальный `settings.json` исключены из Git через `.gitignore`.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Иконка скрыта | Открой стрелку рядом с часами и перетащи T/Z в видимую область |
| Горячая клавиша занята | Выбери другое сочетание в настройках или используй меню иконки |
| Найден отдельно запущенный `winws.exe` | Закрой окно zapret, запущенное вручную через `.bat` |
| Служба zapret отсутствует | Один раз установи её через `service.bat → 1` |
| Не найден файл стратегии | Проверь выбранную папку, наличие `bin`, `lists` и файлов стратегии |
| Обычный Tailscale требует входа | Открой Tailscale и заверши авторизацию |
| Tailscale отключён | Подключи обычный Tailscale; отдельного входа в Switcher нет |
| Exit node не выбран или не в сети | Выбери доступный exit node в обычном приложении Tailscale |
| Сайт из исключений не открывается | Перезапусти браузер или приложение, проверь дополнительные домены сервиса и собственный защищённый DNS браузера |
| Не работает Музыка или другой сервис | Добавь служебные домены сервиса либо правило по имени его EXE; одной записи главного сайта может быть недостаточно |
| Не применяются новые правила | Останови маршрутизацию, сохрани изменения и включи её снова; уже открытые соединения нужно перезапустить |
| Не удалось восстановить подключения | Нажми «Остановить / восстановить» и проверь сообщение; последний журнал — routing-last.log |
| Стратегия изменена через `service.bat` | Открой настройки Switcher и сохрани нужную стратегию |
| Красная иконка `?` | Открой «Подробности» и прочитай сообщение об ошибке |

### Ограничения

- Switcher управляет уже установленными программами и не устанавливает Tailscale или zapret.
- Формат стратегий проверен на zapret 1.10.2; неподдерживаемые команды отклоняются.
- Сетевой режим после перезагрузки автоматически не восстанавливается.
- Проверка логики не гарантирует, что выбранная стратегия обеспечит доступ к нужному сайту в конкретной сети.

## Удаление

Останови маршрутизацию, дождись восстановления подключений, выбери **«Выход»**, затем запусти `Uninstall.cmd` и подтверди запрос Windows.

Удаляются задача Планировщика, ярлык, установленный Switcher и его настройки. Исходный автоматический запуск zapret восстанавливается, если он был включён до установки. Сами Tailscale и zapret остаются установленными.
